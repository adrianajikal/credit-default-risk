# Credit Default Risk Prediction

## Business Objective
Develop a classification model capable of estimating the risk of customer default, supporting credit approval decisions and reducing financial losses.

## Dataset
UCI Default of Credit Card Clients Dataset

## Target
default.payment.next.month (1 = default, 0 = non-default)

## Primary Metric
Recall (default class) and PR-AUC

## Why This Matters
False negatives (approving a client who will default) generate financial loss. Therefore, recall for the default class is prioritized.
